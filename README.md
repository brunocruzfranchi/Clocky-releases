# Clocky downloads

Clocky is a macOS menu-bar app for people whose coworkers live in other time zones: it shows one moment in every city you work with, reads a time the way someone wrote it ("3pm ET Thursday"), and finds a time that suits everyone.

This repository holds only the built app. Get the latest version from [Releases](https://github.com/brunocruzfranchi/Clocky-releases/releases/latest): download the `.dmg`, open it, and drag Clocky to Applications.

- Requires macOS 14 or later, on Intel or Apple silicon.
- Clocky keeps itself up to date after that. `appcast.xml` in this repository is the list of versions it reads; the `.zip` in each release is what it downloads.
